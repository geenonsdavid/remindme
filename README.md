## Rappels d’entretien

Ajoutez un entretien avec son nom et sa date : l’application programme une
notification à 9 h le jour prévu. L’autorisation de notifications est demandée
lors du premier ajout. Sur Android, les rappels planifiés sont rétablis après un
redémarrage de l’appareil. Les notifications ne sont pas disponibles dans la
version Web ; utilisez l’application Android ou iOS pour recevoir les rappels.
